Idle Control Lab for Windows x64

Extract the entire ZIP to a writable folder, then double-click idle-control-lab.exe.
The app uses the Microsoft Edge WebView2 Evergreen Runtime. If it is missing,
install the x64 runtime from https://developer.microsoft.com/microsoft-edge/webview2/
and reopen the app. If Windows reports a missing VCRUNTIME140 DLL, install
the Microsoft Visual C++ x64 Redistributable from
https://aka.ms/vs/17/release/vc_redist.x64.exe. This community build is unsigned.
